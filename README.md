# 尘线突击 / Dustline Raid

作者：Jack · © Jack 版权所有 · 禁止任何形式转载

一款浏览器第一人称波次突击游戏。画面走黄昏沙尘货栈，手感接近经典竞技射击，流程像魂斗罗 / 打飞机：怪会一波波涌出来，打死升级武器，越往后越密，中场和结尾各有头目。

这是大约 10–15 分钟可通关的网页切片，不是商业 3A 成品。

## 试玩

本地：

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173/

截图机位：`/?shot=title|yard|gun|ads|wave|boss|upgrade`

画质：`/?quality=low|medium|high`

## 操作

| 键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 点击画面 | 锁定鼠标视角（也可按住左键拖拽） |
| Shift | 静步 |
| Ctrl | 下蹲 |
| 空格 | 跳 |
| 左键 | 射击 |
| 右键 | 瞄准 |
| R | 换弹 |
| 1–4 / 滚轮 | 切枪 |

手机：左摇杆移动，右侧拖视角，右下按钮射击 / 瞄准 / 换弹 / 跳跃 / 切枪。

## 波次与武器

1. 货栈警戒 → 锈鹰手枪起步，清场后获得 **沙暴冲锋枪**
2. 两侧夹击 → 包扎或弹药
3. 巷口清场 → 在 **尘脊步枪** 与 **巷口霰弹** 中选一把
4. 交叉火力 → 破片手雷
5. 中场头目 **铁罩督战**
6. 沙暴加码 → 伤害或射速强化
7. 人潮决堤 → 全副武装
8. 最终头目 **砂喉重甲**

敌军：面罩突袭兵、钢盔火枪手、短管清场手、投弹手。
