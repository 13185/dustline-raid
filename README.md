# 尘线突击 / Dustline Raid

作者：Jack · © Jack 版权所有 · 禁止任何形式转载

一款浏览器第一人称波次突击游戏，按电脑 FPS 手感来做。画面走黄昏沙尘货栈，流程像魂斗罗 / 打飞机：怪会一波波涌出来，打死升级武器，越往后越密，中场和结尾各有头目。

这是大约 10–15 分钟可通关的网页切片，不是商业 3A 成品。

试玩：https://13185.github.io/dustline-raid/

本地：

```bash
python3 -m http.server 4188
```

然后打开 http://localhost:4188/

截图机位：`/?shot=title|yard|gun|ads|wave|boss|upgrade`

画质：`/?quality=low|medium|high`

## 操作（电脑 FPS）

点击「开始突击」后会锁定鼠标。若按 Esc、切出窗口或失去锁定，会出现「点击继续」，再点一次即可重新锁定。

| 键 | 作用 |
| --- | --- |
| 点击画面 | 锁定鼠标视角 |
| 鼠标移动 | 环视（锁定后） |
| WASD | 移动 |
| Shift | 静步 |
| Ctrl | 下蹲 |
| 空格 | 跳 |
| 左键 | 射击 |
| 按住右键 | 瞄准 / 开镜（松开退出） |
| R | 换弹 |
| 1–4 / 滚轮 | 切枪 |
| G | 手雷 |
| Esc | 暂停并解除鼠标锁定 |

本作按电脑操作设计，没有手机触摸键。

## 波次与武器

1. 货栈警戒 → 锈鹰手枪起步，清场后获得 **沙暴冲锋枪**
2. 两侧夹击 → 包扎或弹药
3. 巷口清场 → 在 **尘脊步枪** 与 **巷口霰弹** 中选一把
4. 交叉火力 → 破片手雷
5. 中场头目 **铁罩督战**
6. 沙暴加码 → 伤害或射速强化
7. 人潮决堤 → 全副武装
8. 最终头目 **砂喉重甲**

敌军：面罩突袭兵、钢盔火枪手、短管清场手、投弹手（参考民兵 / 土匪装束的原创造型）。
