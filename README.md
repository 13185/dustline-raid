# 尘线突击 / Dustline Raid

作者：Jack · © Jack 版权所有 · 禁止任何形式转载

一款浏览器第一人称波次突击游戏，按电脑 FPS 手感来做。画面走黄昏沙尘货栈，流程像魂斗罗 / 打飞机：怪会一波波涌出来，打死升级武器，越往后越密，中场和结尾各有头目。

这是大约 10–15 分钟可通关的网页切片，不是商业 3A 成品。

试玩：https://13185.github.io/dustline-raid/

本地：

```bash
python3 -m http.server 4188
```

然后打开 http://localhost:4188/

截图机位：`/?shot=title|yard|gun|ads|wave|boss|upgrade|bars|lowhp|drops|zombies|rusher|gunner|bile|finalboss`

画质：`/?quality=low|medium|high`

## 操作（电脑 FPS）

点击「开始突击」后会锁定鼠标。若按 Esc、切出窗口或失去锁定，会出现「点击继续」，再点一次即可重新锁定。

| 键 | 作用 |
| --- | --- |
| 点击画面 | 锁定鼠标视角 |
| 鼠标移动 | 环视（锁定后） |
| WASD | 移动 |
| Shift | 静步 |
| Ctrl | 下蹲 |
| 空格 | 跳 |
| 左键 | 射击 |
| 按住右键 | 瞄准 / 开镜（松开退出） |
| R | 换弹 |
| 1–4 / 滚轮 | 切枪 |
| G | 手雷 |
| Esc | 暂停并解除鼠标锁定 |

本作按电脑操作设计，没有手机触摸键。

## 生命、血条与拾取

- 自己的生命在左下角：数值 + 血条，颜色随比例从绿变黄再变红。受伤时屏幕边缘会闪红；生命低于 30% 时会出现心跳式提示「血量过低」。回血时左下角会短暂跳出 `+生命`。
- 敌军头顶有世界空间血条（深绿到红），第一次受伤后显示，或靠近约 30 米内常显。头目额外有屏幕上方的大血条和名字。死亡后隐藏。
- 击倒敌人约有 18% 概率掉落 **补血药品**（+25 生命，不超过上限）、25% 概率掉落 **弹药**（给当前枪补充约两个弹匣的后备弹，其他已拥有的枪各补一个弹匣，不超过初始后备上限）。生命低于 40% 时药品概率升至约 32%。头目固定掉落药品和弹药各一。
- 地上的白底红十字药箱、橄榄色弹药箱会轻微旋转发光。走近约 1.4 米自动拾取；生命已满时不会捡药品（留在地上）。物品约 25 秒后消失，消失前会闪烁。同时最多存在约 20 个掉落物。

## 波次与武器

1. 货栈警戒 → 锈鹰手枪起步，清场后获得 **沙暴冲锋枪**
2. 两侧夹击 → 包扎或弹药
3. 巷口清场 → 在 **尘脊步枪** 与 **巷口霰弹** 中选一把
4. 交叉火力 → 破片手雷
5. 中场头目 **钉板督尸**
6. 沙暴加码 → 伤害或射速强化
7. 人潮决堤 → 全副武装
8. 最终头目 **砂喉尸甲**

敌军（沙市货栈尸潮，原创造型）：腐衣扑咬者、锈枪丧尸、裂颚清场尸、胀袋投掷尸；中场头目钉板督尸，最终头目砂喉尸甲。

## 技术

Three.js r170 + WebGL2。第一人称枪械、敌军角色和部分道具在 Blender 中建模并导出为 glTF；地面与建筑仍用程序化 PBR 贴图。自定义后期（bloom、尘雾光柱、胶片颗粒、ACES 调色）。

## 模型

`art/build_assets.py` 用 Blender 4.2 后台脚本生成 `models/*.glb`。重新导出：

```bash
blender --background --python art/build_assets.py
```
